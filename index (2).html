아티팩트 보상 예측기 보상 유형별 확률 · 내 행운 직접 입력

과일꼬치 6칸, 시작 아티팩트의 시너지, 무기별 등장 제한, 희귀도별 아티팩트 개수와 결속 2중 시너지를 함께 반영합니다. 일반·미니보스·보스 보상을 선택하고, 현재 내 행운 스탯을 직접 입력하면 등급별 확률과 보상 후보가 자동 계산됩니다.

모형의 한계 — 이 결과는 실제 게임 드롭 확률이 아닙니다. 아티팩트 수량은 사용자 제공 데이터이고 보상 종류별 확률식은 비공식 커뮤니티 분석입니다. 희귀도 확률 기준값은 사용자가 제공한 보상별 표 이미지(행운 −50·0·100)를 그대로 전사했습니다. 이것은 비공식 커뮤니티 분석이며 실제 게임 내부 계산과 Star's 모드의 일치 여부는 확인되지 않았습니다. 결속·당근의 세부 보정은 모형 가정입니다. 아이템 이름을 제공받지 않았으므로 개별 아이템은 임시 번호로 표시합니다.

01. 시작 무기

6종

해당 무기에서만 등장하는 아티팩트를 자동으로 걸러냅니다.

02. 과일꼬치

0 / 6칸

시너지마다 일반 과일 최대 +3개, 얼린 과일 최대 −2개. 슬롯 오른쪽에서 수량을 조절하세요.

당근은 보유 시너지 1개당 +25%p, 최대 +75%p로 모델링합니다. 얼린 과일을 선택한 시너지에는 당근 효과가 적용되지 않습니다.

03. 시작 아티팩트

0 / 2개

아티팩트 이름이 아직 없으므로 시너지로 대신 입력합니다. 하나당 해당 시너지 +1, 결속 선택 시 양쪽 시너지 각각 +1로 가정합니다.

현재 보유 중인 시너지 추가 입력

시작 아이템 외 이미 획득한 아티팩트가 있다면 그 시너지 개수를 추가하세요. 당근 보정 및 결속 등장 조건에 반영됩니다.

04. 보상 종류와 행운

보스

일반·석판 / 미니보스 / 보스의 확률표는 별개야. 아래 칸에 네 실제 행운 스탯을 입력하면 선택한 보상 종류에 맞춰 계산돼.

예: 행운 25면 25 입력 · 기준값 행운 −50 / 0 / 100 · 범위를 벗어나면 끝값 적용
보상 종류별 원본 확률표 보기 (기준 데이터)

아래 확률은 사용자가 제공한 이미지의 값입니다. 이 표는 수정할 필요가 없고, 위의 행운 입력칸만 직접 입력하면 됩니다.

계산: 행운 −50→0 구간 및 0→100 구간은 각각 선형 보간. 일반(흰색) 확률 = 100% − (고급 + 희귀 + 전설). 비공식 커뮤니티 분석 원문 · 사용자 제공 이미지 수치 사용

05. 계산 설정

실험 모델

0.10.9 이후 일반 규칙은 양쪽 중 하나가 활성화되면 후보에 추가됩니다. Star's 모드의 별도 규칙은 확인되지 않았습니다.

고급 설정 · 아이템 가중치 조정

아래 값은 희귀도 확률을 바꾸지 않고 같은 희귀도 안에서 아이템에 적용할 추가 가중치입니다. 기본값 1:1:1:1은 동일 등급 내 균등 조건입니다.

결속은 양쪽 시너지의 영향을 받지만 정확한 병합식은 확인되지 않았습니다. 결속 고유 보정 +25%p(당근 적용 시 +50%p)는 별도로 더하는 가정입니다.
